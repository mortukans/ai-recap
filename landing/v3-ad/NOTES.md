# v3 — "the 20-second ad, then the page it inspired"
- Concept: a 20 s commercial (hook -> one tap -> LV+EN waveform -> recap writes itself -> dates fly onto the calendar -> end card) plays in the hero with a synced, clickable chapter bar; the sections below replay the same beats as scroll-revealed "scenes" (slates 01-06, serif + amber-italic headlines, dark "film" bands), ending in plans + App Store.
- Ad route: real HyperFrames (`npx hyperframes@0.9.34`, GSAP composition). Source `ad/hf/index.html` (1920x1080); `node ad/build.mjs` derives `ad/hf-vertical/` (1080x1920); `node ad/build.mjs render` re-renders. EN/LV via the `lang` composition variable (`ad/vars-*.json`).
- Real MP4s exist: `ad/ad-en.mp4`, `ad/ad-lv.mp4`, `ad/ad-en-vertical.mp4`, `ad/ad-lv-vertical.mp4` (1080p, 30 fps, 20 s, silent, ~0.9 MB each — HyperFrames renders re-encoded with ffmpeg CRF 27; the CRF 16 masters were deleted to keep the folder small).
- Hero plays the MP4 for the page language (vertical cut under 720 px); if the video errors it falls back to the live HTML composition in an iframe (`?ad=html` forces it). The same file runs standalone: `ad/hf/index.html?lang=lv&t=7.5` seeks to a frame.
- Reduced motion (or `?still=1`): poster + play button, all scenes fully revealed, nothing animates.
- Debug hooks: `?lang=`, `?theme=`, `?p=0..1` (shows the page as if scrolled; uses a transform because headless Chrome ignores real scroll), `?still=1`. `shot.ps1` + `_shots/phone.html` are the screenshot helpers (headless Chrome cannot go narrower than ~500 px, so phone shots use iframes).
- Real: all product facts, prices, links, LV copy reused from the app/store listing. Illustrative: the fictional "Q4 roadmap review" meeting, the Ask answer "12:40", the record-button demo (a toy, records nothing). App screens are redrawn as HTML cards, not screenshots. The App Store badge is plain text (no Apple logo).
- Not done / gaps: no audio or music in the ad; the `/brag` skill was not available, so the ad was authored by hand; HyperFrames lint still warns (not errors) that scenes should be split into sub-compositions; headline motion and video playback were checked through stills and headless captures, not watched in a live browser; `?p=` hides the difference between real sticky-header scrolling and the shifted capture.
- Weight: folder ~4.5 MB without `_shots/`; one page view loads ~1.1 MB (HTML 60 KB + one MP4 + poster + Google Fonts + nothing else; GSAP only loads inside the fallback iframe).
